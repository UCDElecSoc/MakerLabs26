# Makerlab5 with GOOD WAVES AND BAD VIBES!!
​Ever had a circuit that should work… but just feels off?

⚡ Join Joe Biju for our **1st MakerLab of 2026** :O ⚡

Ever wondered what’s *actually* going on inside a circuit? In this MakerLab, we’ll ditch the guessing and start **seeing the truth** using an **oscilloscope** 🔍📈

You’ll go beyond **“does it turn on?”** and learn how to read **waveforms, timing, noise, and phase** — the difference between **good waves** and **bad vibes** 😌⚡😵‍💫

![Oscilloscope image](/docs/assets/images/Makerlab5-image1.webp)


# We’ll work through **three hands-on stages**:

🌀 **Spin**  
Generate AC waveforms using signal generators and by spinning a brushless motor — and explore why **three-phase power** dominates the real world ⚙️⚡

🔐 **Sync**  
Capture and decode a **secret message** (you may need to clean up noise!)  
🏁 **First team to succeed wins a prize** 🎁👀

🎵 **Sound**  
Push oscilloscopes beyond engineering and create **sick oscilloscope music** 🎛️🎶  
(Watch the first minute of this video!)

By the end of this lab, using an oscilloscope will feel **way less mysterious** — and you’ll be the **saviour** when everyone else is lost 😄🫡

✅ **No prior experience needed**  
Come along for the usual fun + practical learning — see you there! 🚀
